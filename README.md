# ACS Gas Station - Arena Web Security

"ACS Gas Station - Fuel Distribution & Gas Station Management Platform" A realistic Docker-based lab. Difficulty: Beginner -> Advanced (OSCP-style).

## Setup Instructions

This lab is fully containerized using Docker.

1. Ensure you have Docker and Docker Compose installed.
2. Run the following command in this directory:
   ```bash
   docker-compose up --build -d
   ```
3. Access the lab at `http://localhost:8090`

## Features
- Fully functional Gas Station dashboard
- 12+ embedded vulnerabilities (OWASP Top 10)
- Designed for realistic penetration testing training
